AKM GRAFFITI WARS v8.11 — AKM TAG Street with Cyrillic coverage

The uploaded AKM_TAG_Street.ttf contains Latin letters and digits but no native Cyrillic, which caused Russian UI labels to fall back to the browser font. This build adds an extended AKM_TAG_Street_Cyrillic.ttf with block-style Cyrillic glyphs designed to match the supplied typeface. The original font is retained at assets/fonts/AKM_TAG_Street.ttf.

The city map artwork, geometry, markers, hotspots and map interaction logic were not changed.
