AKM GRAFFITI WARS v5.3 — TERRITORY PANEL FIX

This update fixes the selected territory/place card on the interactive map.

Changes:
- Added a visible X close button to the selected territory/place panel.
- Tapping an empty area of the map closes the panel without affecting map dragging.
- Tapping the currently selected territory marker again closes its panel.
- Escape closes the territory panel and the drawer on desktop keyboards.
- The selected territory highlight is cleared when the card closes.
- Existing map scene, panning, zooming, actions, local progress, character, and assets are preserved.

Deploy:
1. Upload this ZIP to Netlify Drop.
2. Open the deployed app on iPhone.
3. Open Map and tap any territory.
4. Close the panel using the X in its upper-right corner, or tap an empty area of the map.

This is a UI interaction fix. It does not change the local-only status of territory scores or multiplayer.
