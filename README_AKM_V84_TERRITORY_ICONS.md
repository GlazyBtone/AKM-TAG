AKM GRAFFITI WARS v8.4 — Territory marker pictograms

This update replaces ambiguous Unicode glyphs inside the seven existing interactive territory pins with clear, native SVG pictograms: apartment blocks (Юбилейный), twin buildings (Дружба), skateboard (Скейт-парк), owl (арт-резиденция «Сова»), monument (Площадь), factory (Промзона), and waves (Озёрный сектор).

No new locations were added. The existing city background, marker positions, colors, interactions, map pan/zoom, snow and window-light effects are preserved. Icons are drawn by SVG code and are not a replacement map image.

Main game file: test-map.html.
