AKM GRAFFITI WARS v5.1 — AUTHORED INTERACTIVE CITY

This build replaces the prior repetitive city-map generator with a hand-authored SVG scene. It is still an interactive game scene, not a flattened map image.

Included:
- authored winter-city layout with connected roads, sidewalks, crosswalks and snow fields;
- distinct Jubilee and Friendship residential courtyard blocks;
- a dedicated Memory Square with paving geometry, lights, benches and a neutral civic memorial;
- an industrial Promzona with warehouse facades and graffiti walls;
- a frozen lake sector with ice markings and a park promenade;
- individually constructed vector buildings with front/side faces, snowy roofs, window lighting, balconies, shop signs, rooftop equipment and murals;
- tappable territory polygons, graffiti-wall objects and landmark pins;
- panning/zooming and existing map HUD / selected-place actions preserved from the previous project.
- no mosque or church objects are included in the authored scene.

Deploy:
1. Upload the ZIP to Netlify Drop.
2. Open the published URL on iPhone.
3. Open Map, drag to pan, use +/- to zoom, tap a territory or graffiti wall.

Notes:
- The map is an authored fictionalized game layout inspired by the northern-city visual direction, not a survey-accurate geographic map.
- Territory scores remain local demo state. No online multiplayer is enabled in this build.
- This archive was checked for JavaScript syntax and ZIP integrity. It has not been visually certified on a physical iPhone; perform a device check after deployment.
