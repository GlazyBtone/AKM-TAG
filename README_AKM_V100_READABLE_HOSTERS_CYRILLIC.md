AKM GRAFFITI WARS v8.20 — readable Hosters + proper Cyrillic

Fixes the readability problems shown in the screenshot:
- Uses the supplied Hosters typeface for Latin letters and numerals.
- Uses a matching graffiti display font with actual Cyrillic glyphs for Russian text, including Я/я and Й/й. The prior Hosters file had blank Cyrillic glyph outlines; mapping them to Latin lookalikes caused the missing/wrong letters.
- Increases font sizes, line-height, button text, labels and card headings in the drawer/task interface.
- Keeps the dark WALL OF TAGS palette and leaves map artwork, marker placement and gameplay logic unchanged.

The visual style is a mixed font family: Hosters for Latin and 129 Fatboy for Cyrillic, because the supplied Hosters OTF has no usable Cyrillic outlines. The original font package is retained. Hosters is marked personal-use-only in its supplied license; obtain a commercial license before commercial release.
