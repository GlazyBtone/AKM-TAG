AKM GRAFFITI WARS v5.9 — APPROVED TERRITORY LAYOUT

This build replaces the provisional territory geometry with the layout approved by the project owner from the marked-up concept image.

Changes:
- Seven independently selectable territory polygons use the approved spatial division: Jubilee, Friendship, Skatepark/Viaduct, Sova Art Residence, Memory Square, Promzona, and Lake Sector.
- Boundaries are straight, clean, and use shared junctions; no permanent outline is displayed on the unselected map.
- Selecting a territory shows its own restrained colored outline and translucent fill; closing the territory panel clears selection and hides the outline.
- Existing pan/zoom, territory panel, graffiti walls, local gameplay and other project assets are retained.

Deploy by uploading the ZIP contents to Netlify Drop.
