AKM GRAFFITI WARS v6.8 — INTERACTIVE TERRITORY MARKERS

Changes:
- Replaced the map image that had territory names and pins baked into the pixels with the clean 941x1672 city artwork already included in the project.
- Added seven native SVG territory markers (Jubilee, Friendship, Skatepark, Sova, Memory Square, Promzona, Lake Sector).
- Territory names are not rendered on the map by default. Tap a marker to open the industrial territory card with the territory name, crew influence percentage, and crew-tag state.
- Territory boundaries remain hidden until a territory is selected.
- Kept the 941:1672 map coordinate system, pan/zoom interaction, existing territory actions, character, and gameplay logic.
- No online backend was added; this remains the local playable project build.
