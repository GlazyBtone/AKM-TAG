# AKM GRAFFITI WARS v8.5 — Territory SVG Icons

Fixes the deployed entry point (`index.html`), which previously still used ambiguous Unicode glyphs despite the earlier test-map change. Each of the seven existing territory pins now draws a small, high-contrast inline SVG pictogram in code: residential buildings, apartment blocks, skateboard, owl, memorial/plaza, factory, and lake waves. No new territories or map background artwork are added. Existing pin colors, coordinates, selection, pan and zoom are preserved. The territory previously named “Площадь Памяти” is now displayed as “Площадь”.

Deploy the contents of this archive to Netlify to see the changes on the live site.
