AKM GRAFFITI WARS v8.21 — readable Hosters + complete Cyrillic

The user's screenshot showed that the prior font's Russian glyphs were wrong: Hosters's supplied OTF has no usable Cyrillic outlines. The earlier fallback used an outlined display font that was hard to read. This build now uses:
- Hosters for Latin letters, numbers and common punctuation.
- Hibiny Bold for actual Cyrillic glyphs, including Я/я and Й/й, so Russian text is legible and the missing letters render correctly.
- Larger drawer headings, card titles, descriptions, stats, buttons and form controls, with improved line-height and padding.

The font family is intentionally split by Unicode range because the Hosters source does not contain complete Cyrillic. The map image, marker positions, map geometry and gameplay logic are unchanged.
