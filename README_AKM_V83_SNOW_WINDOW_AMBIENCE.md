AKM GRAFFITI WARS v8.3 — Snow & Window Ambience

Changes in this build:
- Disabled the animated car, pedestrian, and skater overlays as requested.
- Added intermittent snowfall bursts as an SVG overlay above the existing city artwork.
- Added independently randomized apartment-window lights that switch between off, dim, and warm/cool lit states.
- Kept the original city background asset unchanged.
- Kept interactive territory markers, map pan/zoom, landmark overlays, and the rest of the game UI.

The snow and window lights are generated in the interactive map code; no replacement background image is used.
